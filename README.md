# Go1 Embodied Navigation · 四周学习与复现计划

面向 **Unitree Go1 四足机器人** 的开放词汇语义导航与动态避障研究记录。

**研究目标**：接收语言指令，在平地环境中寻找 **物体、人物或地点**，并在遇到移动行人时进行减速、绕行或安全停车。

> **当前状态：计划阶段（2026-10-28）。** 本仓库包含四周学习计划、论文与开源代码索引、进度表、RTX 5090 环境与 Go1 安全检查规范。没有声称已复现论文结果、已经运行仿真或完成真机安全验证。

## 科研边界与安全原则

- **目标分层**：四周优先验证语义目标搜索、人物跟踪/避让的子模块及接口，不承诺在四周内将所有算法部署到真实 Go1。
- **GPU**：RTX 5090 是共享实验室资源。使用独立 Conda 环境，检查 Blackwell 兼容性，不修改共享系统驱动，不打断其他任务。
- **数据**：HM3D 场景及任务数据应在获授权后下载，并匹配对应版本；不上传受限数据。
- **安全**：导航模型不能保证不撞人；真机自主实验必须在安全审查、人工急停、传感器失效保护和隔离测试通过后进行。
- **复现规范**：作者报告、本地验证、失败和未评测单独标注。日志不包含密钥、实验室网络信息或真人隐私素材。
